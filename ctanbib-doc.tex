\section{Introduction}

This package provides the \package{ctanbib} script, which can be used to
retrieve bibliographic information about packages hosted on CTAN.

It looks up the Catalogue entry for each package name on CTAN (at
\url{https://ctan.org/xml/2.0/pkg/PKGNAME}) and converts relevant information
into a Bib\TeX\ entry.

By default, the \texttt{url} field in the output entry contains the package's
\texttt{home} field value, if specified in the Catalogue entry. Otherwise,
the URL \url{https://ctan.org/pkg/PKGNAME} is used.

\section{Usage}

The script can be used in the following way:

\medskip

\noindent\package{ctanbib [options] $\langle$package-name$\rangle$ \ldots\ $\langle$package-name$\rangle$}

\medskip

The \texttt{curl} utility needs to be installed on the user's system to
download the package information.

By default, the generated entries are formatted for Bib\LaTeX. Use the
\texttt{--bibtex} option to produce plain Bib\TeX\ entries instead.

The output is written to standard output unless the \texttt{--output}
option is used to specify an output file.

\section{Available options}

\begin{description}
  \item[\texttt{-b, --bibtex}] Output plain Bib\TeX\ instead of Bib\LaTeX.
  \item[\texttt{-c, --ctan}] Always use the CTAN \texttt{/pkg/} URL instead of the
    package homepage.
  \item[\texttt{-C, --ctanpath}] Use the package's CTAN path as the URL
    (e.g., \texttt{/support/ctanbib}).
  \item[\texttt{-e, --entrytype}] Change the Bib\TeX\ entry type. The default is
    \texttt{manual}.
  \item[\texttt{-h, --help}] Print the help message.
  \item[\texttt{-l, --labelformat}] Change the label format. The default is
    \texttt{pkgname}. See Section~\ref{sec:labelformats}.
  \item[\texttt{-o, --output}] Write the output to a file instead of standard output.
  \item[\texttt{-p, --pkgname}] Wrap the package name in a
    \verb|\ctanbibpkgname| command.
  \item[\texttt{-s, --separator}] Change the label separator. The default is a colon
    (\texttt{:}).
  \item[\texttt{-v, --version}] Print version information.
\end{description}

\subsection{Label formats}
\label{sec:labelformats}

The \texttt{--labelformat} option accepts the following values:

\begin{description}
  \item[\texttt{pkgname}] Use the package name as the label.
  \item[\texttt{pkgname-version}] Use the package name and version as the
    label. If the version is not available, use the package date instead.
  \item[\texttt{pkgname-date}] Use the package name and date as the label.
  \item[\texttt{pkgname-date-version}] Use the package name, date, and
    version as the label.
  \item[\texttt{pkgname-year}] Use the package name and the year extracted
    from its date as the label.
  \item[\texttt{author-year}] Use the package author and the year extracted
    from its date as the label. If the author is not available, use the
    package name instead.
\end{description}

The \texttt{--separator} option changes the character used to separate
individual parts of the label. The default separator is a colon.

\section{Examples}

\begin{verbatim}
ctanbib latex
\end{verbatim}

\noindent This minimal invocation prints a Bib\LaTeX\ entry to standard
output:

\begin{verbatim}
@manual{latex,
  title = {The LaTeX package},
  subtitle = {A TeX macro package that defines LaTeX},
  author = {Lamport, Leslie and {The LaTeX Project Team}},
  url = {https://www.latex-project.org/},
  urldate = {2026-11-09},
  date = {2026-11-01},
  version = {},
}
\end{verbatim}

\noindent Note that the output does not contain TeX control sequences and
does not preserve capitalization perfectly. The script works only with
the plain-text data available from CTAN; any typesetting refinements are
left to the user.

\subsection{Changing the entry type}

The \texttt{--entrytype} option can be used to change the Bib\TeX\ entry
type:

\begin{verbatim}
ctanbib -e ctan hyperref
\end{verbatim}

\noindent This produces an entry with the \texttt{ctan} type:

\begin{verbatim}
@ctan{hyperref,
  title = {The hyperref package},
  subtitle = {Extensive support for hypertext in LaTeX},
  author = {Oberdiek, Heiko
     and Rahtz, Sebastian
     and {The LaTeX Project Team}},
  url = {https://github.com/latex3/hyperref},
  urldate = {2026-11-09},
  date = {2026-11-03},
  version = {7.01t},
}
\end{verbatim}

\subsection{Generating plain Bib\TeX\ entries}

By default, the script generates Bib\LaTeX\ entries. The \texttt{--bibtex}
option switches to the plain Bib\TeX\ format:

\begin{verbatim}
ctanbib -b hyperref
\end{verbatim}

\noindent This produces the following entry:

\begin{verbatim}
@manual{hyperref,
  title = {The hyperref package},
  author = {Oberdiek, Heiko and Rahtz, Sebastian and {The LaTeX Project Team}},
  year = {2026},
  note = {Package version 7.01t, released 2026-11-03. 
         Available at \url{https://github.com/latex3/hyperref} 
         (accessed 2026-11-11).}
}
\end{verbatim}

\subsection{Choosing the URL}

By default, the package homepage is used as the URL, if available.
The \texttt{--ctan} option forces the use of the CTAN package page instead:

\begin{verbatim}
$ ctanbib -c latex
\end{verbatim}

\noindent This produces an entry that uses the CTAN package page:

\begin{verbatim}
@manual{latex,
  ...
  url = {https://ctan.org/pkg/latex},
  ...
}
\end{verbatim}

The \texttt{--ctanpath} option uses the package's location in the CTAN
directory tree:

\begin{verbatim}
$ ctanbib -C biblatex
\end{verbatim}

\noindent This produces an entry with the CTAN package path as its URL:

\begin{verbatim}
@manual{biblatex,
  ...
  url = {/macros/latex/contrib/biblatex},
  ...
}
\end{verbatim}

\subsection{Formatting package names}

The \texttt{--pkgname} option wraps the package name in the
\verb|\ctanbibpkgname| command:

\begin{verbatim}
$ ctanbib -p latex
\end{verbatim}

\noindent This allows the user to redefine the command to apply custom
formatting to package names:

\begin{verbatim}
@preamble{ "\providecommand\ctanbibpkgname[1]{\textsl{#1}}" }
@manual{latex,
  title = {The \ctanbibpkgname{latex} package},
  ...
}
\end{verbatim}

\subsection{Changing label formats}

The \texttt{--labelformat} option changes the format of the generated
Bib\TeX\ label:

\begin{verbatim}
$ ctanbib -l author-year latex
\end{verbatim}

\noindent This uses the package author and the year extracted from the
package date. If the author is unavailable, the package name is used
instead.

The \texttt{--separator} option changes the separator between label
components. For example:

\begin{verbatim}
$ ctanbib -l author-year -s "-" latex
\end{verbatim}

\noindent uses a hyphen instead of the default colon:

\begin{verbatim}
@manual{Lamport-2026,
  ...
  author = {Lamport, Leslie and {The LaTeX Project Team}},
  date = {2026-11-01},
  ...
}
\end{verbatim}

\subsection{Writing output to a file}

The \texttt{--output} option writes the generated entries to a file instead
of standard output:

\begin{verbatim}
$ ctanbib -o ctanbib.bib latex hyperref
\end{verbatim}
